About CyberGuard

About CyberGuard AI

CyberGuard AI is a local, privacy-first security analysis dashboard: rule-based classification, a machine-learning triage model, batch log analysis, a local knowledge base (RAG), advisory-only conversational AI and a strictly gated Windows defense workflow — all running on this machine.

SECURITY MODEL
  • Binds to the loopback interface only; the UI is reachable from this machine.
  • The AI chat is advisory-only: it never approves, executes or claims privileged actions, and it never touches the defense approval token.
  • State-changing defense actions always follow preview → explicit approval → execute, with CSRF, Host and Origin checks and a local, read-only audit trail.
  • Nothing is persisted: no conversations, no uploaded logs, no cookies, no telemetry, no external requests.
  • All model output is rendered with textContent only — never parsed as HTML.
